# PLAYBENCH

ボードゲームをブラウザで遊べるようにして、その相手がどれだけ強いのかを
**互角の線と並べて実測した図録**です。

遊ぶ場（play）であり、エージェントを測る台（bench）でもある、という名前です。

- 収録作はいずれも単一ファイル。ライブラリもフォントも画像も読み込みません
- 勝率は必ず**互角の線つき**で載せます。4人戦なら .250
- 数値はすべて各作品リポジトリの実測値。出典のない数字は載せません

## 構成

```
index.html          図録の本体
assets/site.css     版面。色・書体・実測プレート
assets/site.js      組版。作品データから画面を組む
data/works.js       収録作品の目録  ← 作品を増やすときはここだけ
games/              各ゲーム本体（取り込みはこれから）
build.js            単一ファイルへの結合
test/shots.js       実ブラウザでの目視検査
```

### 作品を1つ増やす

`data/works.js` の配列に1項足すだけです。`assets/` には手を入れません。
必要なのは、書誌（題・作者・人数・分類）、相手の作り、そして
**互角の線つきの実測値**です。

```js
{
  id: 'newgame', no: 4,
  title: '…', designer: '…', players: '4人', genre: '…',
  method: '…', methodBody: '…',
  plate: {
    baseline: 0.25,                      // 互角の線。3人戦なら .333
    rows: [{ label: 'AI 対 既存CPU 3人', v: 0.62, lead: true }, …]
  },
  play: 'https://…', repo: 'https://…', figure: 'grid'
}
```

`lead: true` を付けた行が朱で描かれます。1つの図版につき1行だけにしてください。
その作品が言いたいことは、たいてい1行のはずです。

## 見た目について

**明の地は製図用紙、暗の地は青焼き**です。同じ図面の2つの複製方式であって、
単純な明暗の反転ではありません。収録作の1つ（ビッグショット）が盤面を
1920年代の都市計画図として描いているので、束ねる側もその素材に合わせています。

色は2つだけ役割を持ちます。

| | |
|---|---|
| 朱 | 主張・朱入れ。その作品が言いたい1行、互角を超えた棒 |
| 藍 | 計測値。比較のための棒、目盛り、注記 |

**実測プレート**がこの図録の骨です。0 から 1.000 の目盛りの上に、
互角の線が全行を貫いて1本立ちます。棒はその線と一緒でなければ読めません。

## 開発

外部依存はありません（目視検査に Playwright を使うときだけ入れます）。

```sh
node build.js                     # dist/playbench.html に1枚化
node test/shots.js                # 実ブラウザで崩れと取りこぼしを見る
python3 -m http.server 8080       # ローカルで開く（file:// でも動きます）
```

`test/shots.js` が見ているのは、コンソールエラーが出ないこと、
横スクロールが出ないこと、作品・段階・作法・構成図が全部組まれていること、
**棒の実幅が値と一致していること**、英語に切り替えても崩れないことです。
明・暗・モバイルの3面を撮って `dist/shots/` に出します。

## これから

順に4段階。**まだどれも実装していません。**

1. **棋譜をとる** ── 打った一手ずつを局面と一緒にブラウザ内に貯める。送信しない
2. **分身をつくる** ── その棋譜を真似るよう学習させ、「あなたのように打つ」相手を作る
3. **倒す相手を鍛える** ── その分身だけを相手に、倒すことに特化した方策を鍛える
4. **闘技場で並べる** ── エージェントは PR で提出。対戦は GitHub Actions が回し、
   結果は JSON でコミットされ、このサイトが読む。サーバーは持たない

3 の中核は、[highsociety の `train/league.js --mode=exploit`](https://github.com/shunshun0904/highsociety)
にすでに動く形で入っています。
