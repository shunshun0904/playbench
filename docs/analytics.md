# アクセス解析（Google アナリティクス 4）

測定IDを1つ貼るだけで動きます。貼るまでは何も読み込みません。

---

## 1. 測定IDを取る

1. <https://analytics.google.com/> を開く
2. **管理**（左下の歯車） → **作成** → **プロパティ**
   - プロパティ名 … `PLAYBENCH`
   - レポートのタイムゾーン … `日本`
   - 通貨 … `日本円`（使いませんが必須です）
3. 業種・規模は適当で構いません。利用目的は「サイトの利用状況を把握する」あたり
4. プラットフォームは **ウェブ** を選ぶ
   - ウェブサイトのURL … `https://shunshun0904.github.io`
     （`/playbench/` まで入れなくてよい。あとでゲーム側に足すときも同じ流れで済む）
   - ストリーム名 … `PLAYBENCH`
5. できた画面の右上に **測定ID** が出ます

```
G-XXXXXXXXXX
```

これだけ控えれば済みます。「タグの実装手順」に出てくるコードは**貼らなくて構いません**。
同じことは `assets/analytics.js` がやっています。

## 2. 貼る

`assets/config.js` の1行だけです。

```js
  analytics: {
    measurementId: 'G-XXXXXXXXXX'
  }
```

push すると Actions が配備します。

## 3. 効いているか確かめる

配備の1〜2分後に、サイトを開いたまま
**GA の レポート → リアルタイム** を見ます。1 が立てば通っています。

立たないときは、この順に疑ってください。

| 症状 | たいてい原因はこれ |
|---|---|
| リアルタイムが 0 のまま | `index.html` がまだキャッシュ（最大10分）。再読み込みする |
| 奥付が「測定IDを入れていないので〜」 | `config.js` が古い。`?v=` が変わるまで待つ |
| 奥付が「追跡拒否（DNT）」 | 自分のブラウザが DNT を出している。「それでも許可する」を押す |
| 拡張機能で止めている | uBlock などは gtag.js ごと落とします。別のブラウザで見る |

## 4. Search Console とつなぐ

つなぐと、**どの検索語で来て、そのあとサイト内で何を見たか**が1つの画面で追えます。

**GA の 管理 → サービス間のリンク設定 → Search Console のリンク** から、
`https://shunshun0904.github.io/playbench/` のプロパティを選びます。

同じ Google アカウントで両方を持っていないとリンクできません。
Search Console 側の登録は [`search-console.md`](search-console.md) を参照。

## このサイトでの決めごと

### 6サイトすべてに同じ測定IDが入っている

プラットフォーム本体と、収録ゲーム5作の `index.html` すべてです。
別リポジトリですが、**同じ測定ID・同じプロパティ**なので、
GA の **レポート → エンゲージメント → ページとスクリーン**で
パスごとに分かれて見えます。

```
/playbench/       プラットフォーム本体
/bigshot/         ビッグショット
/aquire/          アクワイア
/highsociety/     ハイソサエティ
/imperial/        インペリアル
/redplanet/       ミッション・レッドプラネット
```

ゲーム側に入っているのは `index.html` の `<head>` にある `<script>` 1つだけで、
`assets/analytics.js` と同じ判断（`file://` なら何もしない・追跡拒否を尊重・
`localStorage` の `pb-analytics` が `off` なら読み込まない）をします。

**測定IDを変えるときは6か所とも直す必要があります。** playbench は
`assets/config.js`、ゲーム5作は各 `index.html` の `<head>` です。

### 止める手段を3つ用意してある

`assets/analytics.js` が全部です。

1. **測定IDが空** … gtag.js を読み込まない。外部への通信が1本も出ない
2. **ブラウザが拒否を出している** … Global Privacy Control か DNT があれば読み込まない
3. **奥付の「止める」** … `localStorage` に残り、以後は読み込まない。
   すでに読み込んだ後でも `ga-disable-<測定ID>` を立てるので、その場で送信が止まる

このため、**GA の数字は実際の訪問より少なめに出ます。** それでよいと考えています。

### 奥付の文言は状態から作っている

方針（何を集めるか）は `index.html` に書いてあり、
**いまこの端末で実際に計測しているか**は `assets/site.js` が状態から書き出します。
書いてあることと、していることが食い違わないようにするためです。

「何も追跡せず」という以前の記述は、GA を入れた時点で事実でなくなるので消しました。

### 触っていない設定

- **Google シグナル** … 既定のままオフ。広告に使う気がないので入れません
- **IPの匿名化** … GA4 は既定で丸めます。効かない設定を足して「やっている風」にしません
- **データ保持** … 既定は2か月です。**14か月に伸ばすことを勧めます**
  （管理 → データの設定 → データ保持）。伸ばさないと去年との比較ができません

### Cookie と設定の置き場所

`shunshun0904.github.io` に置かれます。`github.io` は公開接尾辞リストに載っていて
ブラウザがドメイン全体への書き込みを拒むため、他人の github.io サイトには漏れません。

逆に**自分の6サイトは同一オリジン**（パスが違うだけ）なので、そこは共有されます。
これは狙ったとおりで、2つ効きます。

- PLAYBENCH からゲームへ移った人が、**同じ人の回遊**としてつながる
- 奥付の**「止める」が6サイトすべてに効く**（`localStorage` の `pb-analytics` を見ている）
